# 케이스 (3D 프린트)

`case.py` 는 [build123d](https://github.com/gumyr/build123d) 로 쓴 파라메트릭 모델입니다.
숫자를 바꾸고 다시 돌리면 `out/` 에 STL 이 새로 나옵니다.

```sh
pip install build123d
python case.py
```

| 파일 | 뭐 | 메모 |
|---|---|---|
| `out/tub.stl` | 깊은 통 (화면 창 · 배터리 칸 · 옆 구멍) | 화면 창이 있는 면을 베드에 |
| `out/lid.stl` | 얇은 뚜껑 (렌즈 구멍 · 카메라 틀) | **이미 뒤집어서 저장** — 그대로 올리면 서포트 없이 뽑힘 |
| `out/fit_gauge.stl` | 핏 확인용 게이지 (네 귀퉁이 + 높이 기둥) | 1cm³, 몇 분. 본 출력 전에 둘레·높이부터 확인 |

**외형 110.7 × 52.2 × 30 mm.** 통에 부품과 선뭉치를 다 넣고 뚜껑을 순간접착제로 붙입니다(나사 없음).

## 왜 이런 모양인가

- **카메라가 고정초점(30cm~∞)** 이라 물체에 갖다 대는 게 아니라 **떨어져서 겨누는** 기기입니다.
  그래서 화면은 내 쪽(통 바닥), 렌즈는 대상 쪽(뚜껑) — 서로 반대 면에 둡니다.
- 원형 화면과 렌즈는 같은 축에 맞춰 둬서, 화면 너머로 겨누면 그곳이 읽힙니다.
- 두께는 배터리(10mm)와 Grove Vision 보드가 정합니다.
